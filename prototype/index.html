Depthwise Separable Convolutions:

MobileNetV2 splits standard convolution into a 3x3 depthwise convolution followed by a 1x1 pointwise linear bottleneck. This achieves an 8.8x reduction in computational operations without compromising feature extraction precision, making it viable on basic Android devices.

Grad-CAM Mathematical Formulation:

α_k^c = (1/Z) * ∑_i ∑_j (∂y^c / ∂A_{i,j}^k)
L_{Grad-CAM}^c = ReLU( ∑_k α_k^c * A^k )

Neuron activation gradients flowing into the final convolutional layer are linearly combined and rectified, projecting a visual saliency heatmap showing which leaf lesions influenced the prediction.
